# Design Frontend

1. Confirmar guía UX/UI y contratos backend aplicables.
2. Ejecutar entrevista Frontend.
3. Aplicar `knowledge-packs/frontend/patterns.md` y paquetes de dominio/UX.
4. Definir rutas, pantallas, componentes y estados visibles.
5. Clasificar estado local, URL, servidor, compartido y persistido.
6. Diseñar errores, reintentos, sesión, permisos y compatibilidad de contratos.
7. Incorporar responsive, accesibilidad, internacionalización y seguridad.
8. Definir pruebas de componente, integración y E2E.
9. Establecer presupuesto de rendimiento y telemetría permitida.
10. Mantener trazabilidad con criterios de aceptación.
