# Explain Discovery Question

1. Identificar pregunta, rol propietario, etapa y decisión que intenta informar.
2. Leer `QUESTION-FACILITATION.md` y el perfil de comunicación vigente.
3. Determinar el nivel de ayuda solicitado: reformular, explicar, ejemplificar, estructurar, explorar opciones o validar comprensión.
4. Responder con el formato mínimo necesario:
   - en palabras simples;
   - qué intenta descubrir;
   - por qué importa;
   - cómo responder;
   - ejemplo ficticio;
   - qué hacer si todavía no se sabe.
5. Traducir términos técnicos y conservar entre paréntesis el término original cuando sea útil.
6. Si existen alternativas frecuentes, presentarlas como opciones, no como requisitos.
7. Después de la respuesta del usuario, resumir hechos, decisiones, supuestos y pendientes.
8. Solicitar confirmación antes de registrar una interpretación con impacto material.

Nunca completar la respuesta en nombre del usuario ni usar el ejemplo como decisión aprobada.
