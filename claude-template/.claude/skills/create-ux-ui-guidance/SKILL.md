# Create UX/UI Guidance

1. Leer alcance y criterios aprobados.
2. Ejecutar la entrevista UX/UI y aplicar el paquete de dominio seleccionado.
3. Definir journey, task flows, arquitectura de información y estados críticos.
4. Resolver happy path, vacíos, carga, éxito, error, permisos y acciones irreversibles.
5. Definir principios visuales, tokens o referencias sin inventar marca.
6. Establecer responsive, accesibilidad y comportamiento de teclado.
7. Crear wireframes o prototipos solo al nivel necesario para reducir riesgo.
8. Registrar decisiones que frontend pueda implementar y QA pueda verificar.
9. Pedir aprobación de flujos antes del detalle visual costoso.
