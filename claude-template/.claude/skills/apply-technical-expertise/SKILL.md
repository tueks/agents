# Apply Technical Expertise

1. Identificar rol, decisión y drivers.
2. Leer solo los paquetes técnicos pertinentes.
3. Comparar alternativas con criterios explícitos y evidencia del proyecto.
4. Diferenciar estándar del proyecto, recomendación y experimento.
5. Consultar documentación oficial para APIs y versiones cambiantes.
6. Evitar introducir patrones por prestigio o familiaridad.
7. Registrar decisiones significativas mediante ADR.
8. Si una elección genera un workflow propio repetible, proponer una skill especializada.
