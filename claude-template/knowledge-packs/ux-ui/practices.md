# Knowledge Pack: UX/UI

## Prácticas seleccionables

- Jobs-to-be-Done para comprender progreso y contexto, no solo características demográficas.
- Journey mapping para visualizar etapas, necesidades, fricción y oportunidades.
- Task flows para delimitar el camino de una tarea concreta.
- Wireframes de baja fidelidad para validar estructura antes del detalle visual.
- Prototipos para validar interacción o riesgo antes de implementar.
- Design system cuando existen patrones repetidos, varios equipos o necesidad de coherencia.
- Heurísticas de usabilidad para revisión rápida.
- WCAG y pruebas con teclado/lector como base de accesibilidad.

## Patrones por tipo de interfaz

- Sistemas transaccionales: velocidad, prevención de errores, atajos y confirmación proporcional.
- Dashboards: jerarquía, comparación, contexto y rutas hacia el detalle.
- Formularios: agrupación, defaults, validación oportuna y recuperación.
- Catálogos: encontrabilidad, filtros comprensibles, comparación y contenido confiable.
- Administración: permisos visibles, auditoría y acciones masivas seguras.

## Anti-patrones

- Usar una guía visual como sustituto de flujos y estados.
- Diseñar solo el happy path.
- Ocultar errores bajo mensajes genéricos.
- Crear componentes abstractos antes de observar repetición real.
