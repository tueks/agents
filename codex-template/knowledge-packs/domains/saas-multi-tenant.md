# Domain Pack: SaaS multi-tenant

## Triggers

Usar para un producto operado como servicio para múltiples organizaciones con aislamiento, suscripción y configuración.

## Capacidades frecuentes

- Tenants, organizaciones, miembros, roles e invitaciones.
- Aislamiento de datos y configuración por tenant.
- Planes, límites, trials, suscripciones y metering.
- Onboarding, administración y soporte delegado.
- Feature flags, personalización e integraciones.
- Exportación, eliminación y portabilidad de datos.

## Preguntas adicionales

- ¿Qué representa un tenant y puede un usuario pertenecer a varios?
- ¿Qué nivel de aislamiento exige cada tipo de dato?
- ¿Qué capacidades y límites cambian por plan?
- ¿Cómo se mide uso y qué sucede al exceder límites?
- ¿Qué personalización se permite sin bifurcar el producto?
- ¿Cómo se exportan o eliminan todos los datos de un tenant?

## Riesgos

- Filtrado de tenant aplicado de forma inconsistente.
- Personalizaciones por cliente convertidas en ramas de código.
- Facturación desacoplada de entitlements reales.
- Operaciones de soporte con acceso excesivo.
